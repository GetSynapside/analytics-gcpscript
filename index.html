🚀 GCP Serverless Ingestor

Synapside Analytics JS SDK

Cliente leve, sem dependências, com namespace isolado para execução simultânea.

📋 Como instalar no seu site (GitHub Pages CDN)

Adicione o código abaixo no <head> do seu site para rodar simultaneamente com o script legado: 

<!-- Synapside Analytics (GCP Serverless) -->
<script>
  window.sAnalyticsGcp_project = 'project_6'; // Seu project_code
  window.sAnalyticsGcp_api = 'https://analytics-receiver-ingestor-98880881604.us-central1.run.app';
  window.sAnalyticsGcp = window.sAnalyticsGcp || function () {
    (window.sAnalyticsGcp.q = window.sAnalyticsGcp.q || []).push(arguments);
  };
</script>
<script src="https://getsynapside.github.io/analytics-gcpscript/dist/sAnalyticsGcp_v1.build.js" async></script>
